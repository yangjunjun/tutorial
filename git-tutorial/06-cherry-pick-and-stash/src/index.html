Cherry-pick & Stash 练习

这个页面用于练习 cherry-pick 和 stash 操作

This page is for practicing cherry-pick and stash operations

练习场景 / Exercise Scenarios

场景 1: Cherry-pick 热修复

在 main 分支修复了一个关键 bug，需要将该修复也应用到 release 分支。

A critical bug was fixed on main. Apply that fix to the release branch too.

场景 2: Stash 紧急切换

正在开发新功能，突然收到紧急 bug 报告。Stash 你的工作，切换分支修 bug，然后回来继续。

Working on a feature when an urgent bug report arrives. Stash your work, switch branches to fix, then resume.
