冲突解决演示 / Conflict Resolution Demo

这个页面展示了 Git 合并冲突的实际场景

This page demonstrates a real Git merge conflict scenario

冲突场景 / Conflict Scenario

假设开发者 A 在 feature/gallery 分支添加了"作品集"链接， 同时开发者 B 在 feature/blog 分支添加了"博客"链接。 两人都修改了导航栏的同一区域，合并时产生冲突。

Suppose Developer A added a "Gallery" link on the feature/gallery branch, while Developer B added a "Blog" link on the feature/blog branch. Both modified the same area of the navbar, causing a merge conflict.

解决步骤 / Resolution Steps

  1. 打开冲突文件，找到冲突标记 / Open the conflicted file and find conflict markers
  2. 决定保留哪些修改 / Decide which changes to keep
  3. 删除冲突标记 / Remove conflict markers
  4. git add 标记为已解决 / Stage to mark as resolved
  5. git commit 完成合并 / Commit to complete the merge
