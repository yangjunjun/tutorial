# 教育学核心原理 / Core Principles of Education

## 学科定位 / Scope

教育学研究学习、教学、课程、评价、教育制度以及个体与社会发展。

Education studies learning, teaching, curriculum, assessment, educational institutions, and individual and social development.

## 知识地图 / Knowledge Map

学习科学 / Learning Sciences、课程论 / Curriculum Studies、教学论 / Pedagogy、教育心理 / Educational Psychology、教育评价 / Assessment、教育管理 / Educational Leadership、比较教育 / Comparative Education、特殊教育 / Special Education、教育技术 / Educational Technology.

## 核心原则 / Core Principles

- 新知识依赖先备知识 / New learning builds on prior knowledge.
- 提取练习和间隔学习有助长期保持 / Retrieval practice and spacing support retention.
- 反馈应及时、具体、可行动 / Feedback should be timely, specific, and actionable.
- 教学、目标和评价需要一致 / Objectives, instruction, and assessment should align.
- 学习差异不应被简单等同于固定能力 / Learning differences should not be reduced to fixed ability.

## 研究方法 / Research Methods

课堂观察 / Classroom Observation、学习实验 / Learning Experiment、行动研究 / Action Research、设计型研究 / Design-Based Research、纵向研究 / Longitudinal Study、项目评估 / Program Evaluation.

## 学习路径 / Learning Path

教育与心理导论 → 学习理论 → 课程教学与评价 → 研究方法 → 学段或专业方向 → 教学实践和反思。

Foundations → learning theory → curriculum, instruction, and assessment → research methods → specialization → practice and reflection.
