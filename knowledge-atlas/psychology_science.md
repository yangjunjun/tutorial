# 心理学核心原理 / Core Principles of Psychology

## 学科定位 / Scope

心理学以科学方法研究行为、认知、情绪、发展及其生物和社会基础。

Psychology scientifically studies behavior, cognition, emotion, development, and their biological and social foundations.

## 知识地图 / Knowledge Map

认知 / Cognitive、发展 / Developmental、社会 / Social、人格 / Personality、临床 / Clinical、神经 / Neuropsychology、教育 / Educational、工业组织 / Industrial-Organizational Psychology.

## 研究方法 / Research Methods

实验 / Experiment、调查 / Survey、观察 / Observation、个案研究 / Case Study、纵向研究 / Longitudinal Study、心理测量 / Psychometrics、神经成像 / Neuroimaging.

## 核心原则 / Core Principles

- 行为由生物、心理和社会因素共同形成 / Behavior reflects biological, psychological, and social factors.
- 相关不证明因果 / Correlation does not prove causation.
- 测量需要信度和效度 / Measurement requires reliability and validity.
- 群体平均不能完全预测个体 / Group averages do not fully predict individuals.
- 临床结论需要专业评估，概念文档不能替代诊疗 / Clinical conclusions require professional assessment.

## 学习路径 / Learning Path

普通心理学 → 统计与研究方法 → 认知、发展、社会、生物心理 → 测量与异常心理 → 应用方向。

General psychology → statistics and research methods → cognitive, developmental, social, and biological psychology → measurement and abnormal psychology → application.
