# 语言学核心原理 / Core Principles of Linguistics

## 学科定位 / Scope

语言学科学研究人类语言的结构、意义、使用、习得、变化及其与心智和社会的关系。

Linguistics scientifically studies the structure, meaning, use, acquisition, and change of human language and its relation to mind and society.

## 知识地图 / Knowledge Map

语音学 / Phonetics、音系学 / Phonology、形态学 / Morphology、句法学 / Syntax、语义学 / Semantics、语用学 / Pragmatics、社会语言学 / Sociolinguistics、心理语言学 / Psycholinguistics、历史语言学 / Historical Linguistics、计算语言学 / Computational Linguistics.

## 核心概念 / Core Concepts

| 中文概念 | English Term | 双语说明 / Bilingual Explanation |
|---|---|---|
| 语言符号 | Linguistic Sign | 形式与意义的约定性结合；a conventional pairing of form and meaning. |
| 音素 | Phoneme | 能区别意义的最小声音单位；the smallest sound unit distinguishing meaning. |
| 语素 | Morpheme | 最小的有意义语言单位；the smallest meaningful linguistic unit. |
| 词 | Word | 具有相对独立形式和功能的单位；a relatively independent unit of form and function. |
| 短语 | Phrase | 围绕中心语组织的词群；a group of words organized around a head. |
| 句法 | Syntax | 词如何组合成短语和句子；how words combine into phrases and sentences. |
| 语义 | Semantics | 语言形式的常规意义；conventional meaning of linguistic forms. |
| 语用 | Pragmatics | 语境如何参与意义解释；how context contributes to interpretation. |
| 指称 | Reference | 表达式与世界中对象的联系；relation between expressions and entities in the world. |
| 语言能力 | Linguistic Competence | 说话者内化的语言知识；a speaker's internalized linguistic knowledge. |
| 语言变体 | Language Variety | 与地区、群体或情境相关的语言形式；a form associated with region, group, or context. |
| 语言变化 | Language Change | 语音、词汇、语法和意义随时间演变；change in sound, vocabulary, grammar, and meaning over time. |

## 核心原则 / Core Principles

- 描写语言实际使用，不把单一规范当作全部语言 / Describe actual usage rather than reducing language to one norm.
- 所有自然语言都具有系统结构 / Every natural language has systematic structure.
- 语言变化是正常过程 / Language change is normal.
- 方言不是“错误语言” / A dialect is not defective language.
- 意义来自形式、语境、知识和互动 / Meaning arises from form, context, knowledge, and interaction.

## 研究方法 / Research Methods

语料库分析 / Corpus Analysis、田野调查 / Fieldwork、声学实验 / Acoustic Experiment、语法判断 / Acceptability Judgment、心理语言实验 / Psycholinguistic Experiment、计算建模 / Computational Modeling.

## 学习路径 / Learning Path

语言学导论 → 语音音系 → 形态句法 → 语义语用 → 语言习得、社会变化和计算方向。

Introduction → phonetics and phonology → morphology and syntax → semantics and pragmatics → acquisition, social change, and computational specialization.
