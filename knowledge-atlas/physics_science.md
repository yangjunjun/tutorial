# 物理学核心原理 / Core Principles of Physics

## 学科定位 / Scope

物理学研究物质、能量、空间、时间及其相互作用，追求用可检验的定律解释自然现象。

Physics studies matter, energy, space, time, and their interactions, seeking testable laws that explain natural phenomena.

## 核心概念 / Core Concepts

| 中文概念 | English Term | 双语说明 / Bilingual Explanation |
|---|---|---|
| 测量 | Measurement | 将物理量与标准单位比较；comparison of a physical quantity with a standard unit. |
| 参考系 | Frame of Reference | 描述位置和运动所依据的坐标系统；a coordinate system used to describe position and motion. |
| 运动 | Motion | 物体位置随时间的变化；change of position over time. |
| 力 | Force | 改变物体运动状态的相互作用；an interaction that changes motion. |
| 动量 | Momentum | 质量与速度的乘积；the product of mass and velocity. |
| 能量 | Energy | 系统做功或引起变化的能力；the capacity of a system to do work or cause change. |
| 守恒定律 | Conservation Law | 封闭系统中某些总量保持不变；certain totals remain constant in a closed system. |
| 熵 | Entropy | 微观状态数量或能量分散程度的度量；a measure of multiplicity or energy dispersal. |
| 场 | Field | 为时空每一点赋予物理量；assigns a physical quantity to each point in spacetime. |
| 波 | Wave | 扰动在空间和时间中的传播；propagation of a disturbance through space and time. |
| 时空 | Spacetime | 将空间和时间统一描述的结构；a unified structure combining space and time. |
| 量子态 | Quantum State | 描述量子系统可知信息的数学对象；a mathematical object encoding information about a quantum system. |
| 不确定性原理 | Uncertainty Principle | 某些共轭物理量不能同时任意精确；certain conjugate quantities cannot both be arbitrarily precise. |

## 基本原理 / Fundamental Principles

- 牛顿运动定律 / Newton's Laws of Motion
- 能量、动量和角动量守恒 / Conservation of energy, momentum, and angular momentum
- 热力学定律 / Laws of Thermodynamics
- 麦克斯韦方程组 / Maxwell's Equations
- 最小作用量原理 / Principle of Least Action
- 狭义与广义相对论 / Special and General Relativity
- 波粒二象性 / Wave-Particle Duality
- 对称性与守恒量 / Symmetry and Conservation

## 研究方法 / Research Methods

观察 / Observation → 假设 / Hypothesis → 数学模型 / Mathematical Model → 实验 / Experiment → 误差分析 / Error Analysis → 重复验证 / Replication.

## 关键对照 / Key Comparisons

- 经典与量子 / Classical vs. Quantum：宏观近似与微观规律。
- 确定性与概率性 / Deterministic vs. Probabilistic：唯一轨迹与概率预测。
- 标量与矢量 / Scalar vs. Vector：只有大小与同时具有大小方向。
- 精确度与准确度 / Precision vs. Accuracy：重复一致程度与接近真值程度。

## 学习路径 / Learning Path

代数与微积分 → 力学 → 电磁学 → 波与光学 → 热力学 → 相对论与量子力学 → 专业方向。

Algebra and calculus → mechanics → electromagnetism → waves and optics → thermodynamics → relativity and quantum mechanics → specialization.
