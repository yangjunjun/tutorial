# 传播学与媒体研究核心原理 / Core Principles of Communication and Media Studies

## 学科定位 / Scope

传播学研究意义如何在人际、组织、公共和媒介系统中被产生、传递、解释与争夺。

Communication studies how meaning is produced, transmitted, interpreted, and contested in interpersonal, organizational, public, and mediated systems.

## 知识地图 / Knowledge Map

人际传播 / Interpersonal Communication、组织传播 / Organizational Communication、大众传播 / Mass Communication、新闻学 / Journalism、公共关系 / Public Relations、广告 / Advertising、数字媒体 / Digital Media、政治传播 / Political Communication、视觉传播 / Visual Communication.

## 核心概念 / Core Concepts

| 中文概念 | English Term | 双语说明 / Bilingual Explanation |
|---|---|---|

## 核心原则 / Core Principles

- 传播不是简单传输，而是共同建构意义 / Communication constructs meaning, not merely transmits it.
- 媒介形式影响信息的范围、速度和表达 / Media forms shape reach, speed, and expression.
- 受众会主动解释，不是被动容器 / Audiences actively interpret messages.
- 传播权力体现在可见性、规则和基础设施 / Communication power operates through visibility, rules, and infrastructure.
- 信息流行度不等于真实性 / Popularity is not equivalent to truth.

## 学习路径 / Learning Path

传播理论 → 新闻与媒介史 → 定量和质性方法 → 数字平台与视觉叙事 → 专业实践和伦理。

Communication theory → journalism and media history → quantitative and qualitative methods → digital platforms and visual storytelling → professional practice and ethics.
