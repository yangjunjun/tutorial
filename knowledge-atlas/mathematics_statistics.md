# 数学与统计核心原理 / Core Principles of Mathematics and Statistics

## 学科定位 / Scope

数学研究数量、结构、空间、变化与形式推理；统计学研究如何从不确定数据中描述、推断和决策。

Mathematics studies quantity, structure, space, change, and formal reasoning. Statistics studies description, inference, and decision-making under uncertainty.

## 核心概念 / Core Concepts

## 主要分支 / Major Branches

- 数论 / Number Theory：整数及其性质 / integers and their properties.
- 抽象代数 / Abstract Algebra：群、环、域 / groups, rings, and fields.
- 线性代数 / Linear Algebra：向量空间和线性变换 / vector spaces and linear transformations.
- 实分析与复分析 / Real and Complex Analysis：极限、连续和函数 / limits, continuity, and functions.
- 微分方程 / Differential Equations：变化率之间的关系 / relationships among rates of change.
- 拓扑学 / Topology：连续变形下保持的性质 / properties preserved under continuous deformation.
- 组合数学 / Combinatorics：计数和离散结构 / counting and discrete structures.
- 运筹学 / Operations Research：约束下优化决策 / optimization of decisions under constraints.

## 研究原则 / Research Principles

- 严格性 / Rigor：每一步推理都必须有依据。
- 抽象性 / Abstraction：从具体问题提取共同结构。
- 可复现性 / Reproducibility：统计分析应允许独立复核。
- 不确定性量化 / Uncertainty Quantification：结论应表达误差和假设。
- 相关不等于因果 / Correlation Is Not Causation。

## 学习路径 / Learning Path

算术与代数 → 几何与函数 → 微积分 → 线性代数 → 概率统计 → 离散数学与证明 → 专业分支。

Arithmetic and algebra → geometry and functions → calculus → linear algebra → probability and statistics → discrete mathematics and proof → specialization.
