# 工程与技术核心原理 / Core Principles of Engineering and Technology

## 学科定位 / Scope

工程学运用科学、数学和经验，在现实约束下设计、制造并维护满足需求的系统。

Engineering applies science, mathematics, and experience to design, build, and maintain systems that meet needs under real-world constraints.

## 知识地图 / Knowledge Map

机械 / Mechanical、土木 / Civil、电气电子 / Electrical and Electronic、化工 / Chemical、材料 / Materials、航空航天 / Aerospace、生物医学 / Biomedical、工业与系统 / Industrial and Systems、能源 / Energy Engineering.

## 核心概念 / Core Concepts

| 中文概念 | English Term | 双语说明 / Bilingual Explanation |
|---|---|---|
| 需求 | Requirement | 系统必须满足的功能或质量条件；a functional or quality condition a system must satisfy. |
| 约束 | Constraint | 成本、时间、材料、法规等限制；a limit involving cost, time, materials, regulation, or other factors. |
| 设计 | Design | 将需求转化为可实现方案；translation of requirements into a realizable solution. |
| 模型 | Model | 对真实系统的有目的简化；a purposeful simplification of a real system. |
| 原型 | Prototype | 用于学习和验证的早期实现；an early implementation used for learning and validation. |
| 优化 | Optimization | 在约束下寻找最佳可行方案；finding the best feasible solution under constraints. |
| 安全系数 | Factor of Safety | 承载能力相对于预期负载的裕量；the margin of capacity over expected load. |
| 可靠性 | Reliability | 系统在规定条件和时间内正常工作的概率；probability of correct operation under stated conditions and time. |
| 鲁棒性 | Robustness | 面对扰动和不确定性仍保持性能；ability to maintain performance under disturbance and uncertainty. |
| 反馈控制 | Feedback Control | 根据输出误差调整输入；adjustment of input based on output error. |
| 生命周期 | Life Cycle | 从需求、设计到退役的全过程；the full process from requirements and design to retirement. |
| 可维护性 | Maintainability | 系统被诊断、修复和升级的难易程度；ease of diagnosis, repair, and upgrade. |

## 工程流程 / Engineering Process

问题定义 / Problem Definition → 需求分析 / Requirements → 概念设计 / Concept Design → 建模仿真 / Modeling and Simulation → 原型 / Prototype → 测试验证 / Verification and Validation → 制造部署 / Production and Deployment → 运维退役 / Operations and Retirement.

## 核心原则 / Core Principles

- 权衡性能、成本、安全和可持续性 / Balance performance, cost, safety, and sustainability.
- 验证“是否按设计制造”，确认“是否满足真实需求” / Verification asks whether it was built right; validation asks whether the right thing was built.
- 故障应被预见、隔离和安全处理 / Failures should be anticipated, isolated, and handled safely.
- 标准化与模块化降低复杂度 / Standardization and modularity reduce complexity.
- 工程伦理要求保护公众安全 / Engineering ethics prioritizes public safety.

## 学习路径 / Learning Path

数学物理 → 工程制图与计算 → 力学、电路、材料、热流体 → 建模控制 → 设计项目 → 专业方向。

Mathematics and physics → technical drawing and computing → mechanics, circuits, materials, and thermofluids → modeling and control → design projects → specialization.
