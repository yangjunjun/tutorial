# 主要学科双语知识图谱 / Bilingual Atlas of Major Disciplines

## 定位 / Purpose

本知识库按现代学术门类整理主要学科。每份分文档采用统一结构：学科定义、知识地图、核心原理、主要分支、研究方法、关键对照和学习路径。

This atlas organizes major fields of modern knowledge. Every document follows a shared structure: definition, knowledge map, core principles, major branches, research methods, key comparisons, and learning path.

“所有学科”无法形成绝对封闭的清单，因为学科会不断交叉和细分。本图谱以一级学科群为边界，并在各文档内覆盖主要子学科。

No absolutely closed list of all disciplines exists because fields continually intersect and specialize. This atlas uses broad disciplinary families and covers their major subfields within each document.

## 统一阅读方法 / How to Read the Atlas

1. 先读“知识地图”，理解学科边界。 / Start with the knowledge map to understand scope.
2. 再读“核心原理”，建立概念骨架。 / Study core principles to build a conceptual framework.
3. 使用“主要分支”选择深入方向。 / Use major branches to select a specialization.
4. 通过“研究方法”理解知识如何被验证。 / Learn how claims are tested through research methods.
5. 按“学习路径”逐步建立先修关系。 / Follow the learning path to respect prerequisites.
