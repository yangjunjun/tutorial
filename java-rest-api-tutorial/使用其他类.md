在 Java 中使用另一个类（或接口、枚举、Record），是否需要 import 取决于它们之间的包关系。可以分成以下几种情况：

不需要 import 的情况

第一种是同一个包内。两个类声明了相同的 package，无论物理上在哪个目录，都可以直接互相引用：

// com/example/User.java
package com.example;
public class User { }

// com/example/UserService.java
package com.example;
public class UserService {
    private User user;  // 同包，直接用
}

第二种是 java.lang 包下的类。这个包是 Java 语言的核心包，编译器自动引入，String、Integer、Object、System、Math、Exception、Thread 等都不需要 import。

第三种是内部类引用外部类。非静态内部类可以直接访问外部类的所有成员，不需要 import。

第四种是同一个文件中定义的类。一个 .java 文件中可以定义多个类（但只能有一个 public 类），它们之间可以直接互相引用。

需要 import 的情况

不同包下的类互相引用，必须 import：

package com.example.service;

import com.example.model.User;          // 导入具体类
import com.example.util.StringHelper;    // 导入工具类
import java.util.List;                   // 导入标准库非 java.lang 的类
import java.time.LocalDateTime;

public class UserService {
    private List<User> users;            // List 和 User 都是 import 来的
}

也可以用通配符  导入整个包，但不推荐，会降低可读性且可能引起命名冲突：

import java.util.;       // 导入 util 包下所有类
import com.example.model.; // 导入 model 包下所有类

 只导入直接子项，不递归导入子包。比如 import java.util. 不会导入 java.util.concurrent 下的类。

静态导入（import static）

如果想直接使用另一个类的静态成员而不加类名前缀，用 import static：

import static java.lang.Math.PI;
import static java.lang.Math.sqrt;
import static com.example.Constants.MAX_RETRY;

public class Calculator {
    double r = sqrt(2.0);        // 不需要写 Math.sqrt
    double circumference = 2  PI  radius;  // 不需要写 Math.PI
}

同样可以通配符导入：import static java.lang.Math.。适合频繁使用某个工具类的场景，但滥用会让代码可读性变差。

命名冲突的处理

两个不同包下有同名类时，不能同时 import，必须至少有一个用全限定名：

import java.util.Date;
// import java.sql.Date;   // 不能同时导入，会冲突

public class Demo {
    private java.util.Date utilDate;     // 用全限定名
    private java.sql.Date sqlDate;       // 用全限定名
}

或者只 import 其中一个，另一个用全限定名：

import java.util.Date;

public class Demo {
    private Date utilDate;                // 走 import
    private java.sql.Date sqlDate;        // 全限定名
}

子类与包的关系

子类继承父类时，如果不在同一个包里，需要 import 父类。但父类的 protected 和 public 成员可以直接使用，不需要额外 import 它们各自的类型（前提是这些类型也已经被父类所在包 import 了）。

子类实现不同包的接口也同理：

package com.example.impl;

import com.example.api.Drawable;   // 接口在另一个包，需要 import

public class Circle implements Drawable {
    @Override
    public void draw() { ... }
}

完整对照

| 场景 | 是否需要 import |
|---|---|
| 同一个 package 下的类 | 不需要 |
| java.lang 下的类 | 不需要（自动引入） |
| 同一个 .java 文件中的类 | 不需要 |
| 内部类访问外部类 | 不需要 |
| 不同 package 的类 | 需要 |
| java.util、java.io 等标准库非 java.lang 的类 | 需要 |
| 第三方库的类 | 需要 |
| 静态成员免前缀使用 | 需要 import static |
| 同名类冲突 | 至少一个用全限定名 |

核心规则就一句话：同包不用导，异包必须导，java.lang 是唯一的例外。
