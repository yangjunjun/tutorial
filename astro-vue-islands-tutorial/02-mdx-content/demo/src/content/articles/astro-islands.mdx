# 理解 Astro Islands 架构

Astro Islands（又称"群岛架构"）是一种现代 Web 架构模式，
它将页面的大部分内容以**静态 HTML** 形式输出，只在需要交互的地方嵌入"岛屿"。

## 核心理念

传统 SPA 会将整个页面打包为一个大型 JavaScript 应用，而 Astro 的做法恰恰相反：

1. **服务端渲染** —— 页面默认输出纯 HTML
2. **按需水合** —— 只有交互组件才加载 JS
3. **零 JS 默认** —— 静态部分不产生任何客户端开销

<Callout type="info" title="群岛架构图">
  想象一个页面是一大片静态海洋（HTML），
  上面散布着若干小岛（Vue / React / Svelte 组件）。
  每个岛独立运行，互不干扰。
</Callout>

## 代码示例

### 页面组件（Astro）

```astro
---
import StaticHeader from '../components/StaticHeader.astro';
import InteractiveSearch from '../components/vue/Search.vue';
---

<StaticHeader />
<!-- 这个 Vue 组件是一个"岛屿" -->
<InteractiveSearch client:load />
```

### 交互式岛屿（Vue）

```vue
<script setup>
import { ref } from 'vue';

const query = ref('');
</script>

<template>
  <input v-model="query" placeholder="搜索..." />
  <p>你正在搜索：{{ query }}</p>
</template>
```

<Callout type="warning">
  注意：岛屿之间的状态默认是隔离的。如果需要跨岛屿通信，
  可以使用 Nano Stores 等共享状态方案。
</Callout>

## 性能优势

| 指标 | SPA | Astro Islands |
|------|-----|---------------|
| 首屏加载 | 慢（需下载整个 bundle） | 快（纯 HTML） |
| JavaScript 体积 | 大 | 最小（仅岛屿） |
| SEO | 需额外配置 SSR | 天然友好 |

## 总结

Astro Islands 让你两全其美：拥有静态站点的性能，同时保留动态交互的能力。
