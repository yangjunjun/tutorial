# Astro 入门指南

如果你正在寻找一个简单、快速的方式来构建现代网站，那么 **Astro** 可能是你最好的选择。在这篇文章中，我们将从零开始，一步步搭建你的第一个 Astro 项目。

## 什么是 Astro？

Astro 是一个现代化的静态站点生成器（SSG），它的核心理念是：

- **零 JavaScript 默认输出**：页面默认生成纯 HTML，不附带任何客户端 JS
- **组件群岛架构**：只在需要交互的地方引入 JS
- **多框架支持**：可以在同一项目中使用 React、Vue、Svelte 等

## 快速开始

### 创建项目

使用官方 CLI 创建新项目：

```bash
npm create astro@latest my-blog
cd my-blog
npm install
```

### 项目结构

创建完成后，你的项目结构如下：

```
my-blog/
├── src/
│   ├── pages/        # 页面文件
│   │   └── index.astro
│   └── layouts/      # 布局文件
├── public/           # 静态资源
├── astro.config.mjs  # 配置文件
└── package.json
```

### 第一个页面

打开 `src/pages/index.astro`，你会看到：

```astro
---
// 这里是组件脚本（仅在构建时运行）
const title = "Hello, Astro!";
---

<html>
  <head>
    <title>{title}</title>
  </head>
  <body>
    <h1>{title}</h1>
    <p>欢迎来到我的第一个 Astro 网站！</p>
  </body>
</html>
```

## 核心概念

### 1. 组件

Astro 组件以 `.astro` 为后缀，由三部分组成：

```astro
---
// 前置脚本：接收 props，处理数据
const { name } = Astro.props;
---

<!-- 模板：生成 HTML -->
<div class="greeting">
  <h2>你好，{name}！</h2>
</div>

<!-- 样式：自动局部作用域 -->
<style>
  .greeting {
    color: #6366f1;
  }
</style>
```

### 2. 路由

Astro 基于文件系统的路由非常直观：

| 文件路径 | 生成的 URL |
|---------|-----------|
| `src/pages/index.astro` | `/` |
| `src/pages/about.astro` | `/about` |
| `src/pages/blog/[slug].astro` | `/blog/:slug` |

### 3. Markdown 支持

Astro 原生支持 Markdown，你可以直接创建 `.md` 文件：

```markdown
---
layout: ../layouts/BlogLayout.astro
title: "我的第一篇文章"
---

这是文章的内容，支持 **Markdown** 语法。
```
