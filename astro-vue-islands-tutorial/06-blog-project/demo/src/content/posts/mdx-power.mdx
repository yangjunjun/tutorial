# MDX 的强大之处

**MDX** 是 Markdown 的超集，它允许你在 Markdown 文档中直接使用 JSX 组件。在 Astro 中，MDX 与 Content Collections 结合，为内容创作带来了前所未有的灵活性。

## MDX 基础

### 什么是 MDX？

MDX = Markdown + JSX。它让你可以：

- 像写普通 Markdown 一样写文章
- 在任意位置插入组件
- 使用 JavaScript 表达式
- 导入和使用任何框架的组件

### 在 Astro 中使用 MDX

首先安装 MDX 集成：

```bash
npx astro add mdx
```

然后在 `astro.config.mjs` 中添加：

```javascript
import { defineConfig } from 'astro/config';
import mdx from '@astrojs/mdx';

export default defineConfig({
  integrations: [mdx()],
});
```

## 组件嵌入示例

### 自定义 Callout 组件

创建一个提示框组件：

```astro
---
// src/components/Callout.astro
const { type = 'info' } = Astro.props;

const icons = {
  info: '💡',
  warning: '⚠️',
  error: '❌',
  success: '✅',
};
---

<div class={`callout callout-${type}`} role="note">
  <span class="icon">{icons[type]}</span>
  <div class="content">
    <slot />
  </div>
</div>

<style>
  .callout {
    padding: 1rem 1.5rem;
    border-radius: 8px;
    margin: 1.5rem 0;
    display: flex;
    gap: 0.75rem;
    border-left: 4px solid;
  }
  .callout-info {
    background: #eff6ff;
    border-color: #3b82f6;
  }
  .callout-warning {
    background: #fefce8;
    border-color: #eab308;
  }
  .callout-error {
    background: #fef2f2;
    border-color: #ef4444;
  }
  .callout-success {
    background: #f0fdf4;
    border-color: #22c55e;
  }
  .icon {
    font-size: 1.25rem;
    flex-shrink: 0;
  }
</style>
```

在 MDX 文件中使用：

```mdx
import Callout from '../components/Callout.astro';

# 我的文章

普通 Markdown 内容...

<Callout type="warning">
  这是一个警告提示框！注意生产环境中的性能影响。
</Callout>

继续写 Markdown...
```

## Content Collections 集成

### 定义 Schema

```typescript
// src/content/config.ts
import { z, defineCollection } from 'astro:content';

const docs = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    description: z.string(),
    // MDX 特有的 frontmatter 字段
    components: z.array(z.string()).optional(),
    toc: z.boolean().default(true),
  }),
});
```

### 渲染 MDX 内容

```astro
---
import { getEntryBySlug } from 'astro:content';

const entry = await getEntryBySlug('docs', 'getting-started');
const { Content, headings } = await entry.render();
---

<article>
  <h1>{entry.data.title}</h1>
  <Content />
</article>
```

## MDX vs 普通 Markdown 对比

| 特性 | Markdown | MDX |
|------|----------|-----|
| 标准语法 | 支持 | 支持 |
| 嵌入组件 | 不支持 | 支持 |
| JavaScript 表达式 | 不支持 | 支持 |
| 导入模块 | 不支持 | 支持 |
| 自定义元素 | 不支持 | 支持 |
| 构建速度 | 快 | 略慢 |

## 最佳实践

### 1. 保持内容语义化

```mdx
<!-- 好的做法：使用语义化组件 -->
<Callout type="info">
  这里使用语义化的 Callout 组件。
</Callout>

<!-- 避免的做法：滥用 div -->
<div style="background: blue; padding: 20px;">
  不要这样做，缺乏语义和可访问性。
</div>
```

### 2. 组件不要过于复杂

MDX 中的组件应该保持简单，专注于增强内容展示。复杂的交互逻辑应该放在独立的 Vue Island 中。

### 3. 合理使用 Frontmatter

```yaml
---
title: "文章标题"
description: "文章描述"
# 记录使用了哪些组件，便于后续维护
components:
  - Callout
  - CodeDemo
  - ChartWidget
toc: true
---
```

## 总结

MDX 将内容创作提升到了一个新的层次。通过合理使用 MDX 组件，你可以创建丰富的交互式文档和博客内容，同时保持 Markdown 的简洁和可读性。
