# 构建完整博客：实战指南

在这个系列中，我们已经学习了 Astro 的基础、Vue Islands 架构和 MDX 内容增强。现在是时候将这些知识整合起来，构建一个真正可以上线的完整博客了。

## 项目规划

## Content Collections 设计

### Schema 定义

```typescript
// src/content/config.ts
import { z, defineCollection } from 'astro:content';

const posts = defineCollection({
  type: 'content',
  schema: ({ image }) => z.object({
    title: z.string(),
    date: z.coerce.date(),
    updatedDate: z.coerce.date().optional(),
    author: z.string(),
    description: z.string(),
    tags: z.array(z.string()),
    category: z.enum(['教程', '深度', '实战', '工具', '随笔']),
    draft: z.boolean().optional().default(false),
    cover: image().optional(),
  }),
});

export const collections = { posts };
```

### 关键设计决策

1. **`type: 'content'`**：支持 MDX 组件渲染
2. **`z.coerce.date()`**：自动将日期字符串转为 Date 对象
3. **`image()`**：支持本地图片引用和自动优化
4. **`draft` 字段**：构建时可以跳过草稿文章

## 页面路由设计

```
首页 (/)
├── 博客列表 (/blog)
│   └── 文章详情 (/blog/[slug])
├── 标签 (/tags)
│   └── 标签详情 (/tags/[tag])
├── 搜索 (/search)
└── 关于 (/about)
```

### 动态路由示例

```astro
---
// src/pages/blog/[...slug].astro
import { getCollection } from 'astro:content';
import PostLayout from '../../layouts/PostLayout.astro';

export async function getStaticPaths() {
  const posts = await getCollection('posts', ({ data }) => {
    // 过滤掉草稿文章
    return data.draft !== true;
  });

  return posts.map((post) => ({
    params: { slug: post.slug },
    props: { post },
  }));
}

const { post } = Astro.props;
const { Content, headings } = await post.render();
---

<PostLayout post={post} headings={headings}>
  <Content />
</PostLayout>
```

## 组件设计

### 文章卡片

```astro
---
// src/components/PostCard.astro
interface Props {
  title: string;
  date: Date;
  description: string;
  tags: string[];
  href: string;
}

const { title, date, description, tags, href } = Astro.props;

// 格式化日期
const formattedDate = date.toLocaleDateString('zh-CN', {
  year: 'numeric',
  month: 'long',
  day: 'numeric',
});
---

<a href={href} class="post-card">
  <div class="card-content">
    <time datetime={date.toISOString()}>{formattedDate}</time>
    <h3>{title}</h3>
    <p>{description}</p>
    <div class="tags">
      {tags.map(tag => (
        <span class="tag">{tag}</span>
      ))}
    </div>
  </div>
</a>
```

## 交互功能实现

### 客户端搜索

搜索功能需要加载全部文章数据，因此使用 Vue Island：

```astro
---
import { getCollection } from 'astro:content';
import SearchWidget from '../components/vue/SearchWidget.vue';

const posts = await getCollection('posts');
const searchData = posts.map(post => ({
  title: post.data.title,
  description: post.data.description,
  tags: post.data.tags,
  slug: post.slug,
}));
---

<SearchWidget client:load posts={searchData} />
```

### 暗黑模式

使用 Nano Store 实现跨组件主题共享：

```typescript
// src/stores/theme.ts
import { atom } from 'nanostores';

type Theme = 'light' | 'dark';

export const $theme = atom<Theme>('light');

// 初始化时从 localStorage 读取
if (typeof window !== 'undefined') {
  const saved = localStorage.getItem('theme') as Theme;
  if (saved) $theme.set(saved);
}
```
