# Maven 实战教程：从入门到多模块项目

> 面向有 Java 基础的开发者，通过示例项目系统掌握 Maven 构建工具的核心能力。每个章节都包含可运行的完整项目。

## 前置要求

- Java 17+（已配置 JAVA_HOME）
- Maven 3.9+（或使用 Maven Wrapper）
- 基础的 Java 编程能力
- 命令行基本操作

安装参考：https://maven.apache.org/install.html

```
Maven 基础概念 → 项目结构 → 依赖管理 → 生命周期与插件
                                              ↓
综合实战项目 ← 测试集成 ← 环境配置 ← 多模块项目
```

## 快速开始

每个章节都是独立可运行的 Maven 项目：

```bash
cd 01-maven-basics/hello-maven
mvn package
java -jar target/hello-maven-1.0.0.jar
```

## 约定

- `$` 前缀表示终端命令
- 代码块标注文件路径
- 每个章节的 `readme.md` 包含完整操作步骤
- 所有示例项目都可直接 `mvn` 构建运行
