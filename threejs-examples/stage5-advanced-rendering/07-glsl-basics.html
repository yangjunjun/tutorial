GLSL 基础 / GLSL Fundamentals

四个面板展示 GLSL 着色器基础：uniform、varying、vec 运算和 gl_FragColor。

Four panels demonstrate GLSL shader basics.

1. 纯色 / Solid Color
void main() { gl_FragColor = vec4(1.0, 0.3, 0.5, 1.0); }
2. UV 渐变 / UV Gradient
varying vec2 vUv; void main() { gl_FragColor = vec4(vUv.x, vUv.y, 0.5, 1.0); }
3. 条纹 / Stripes (sin/fract)
varying vec2 vUv; void main() { float s = sin(vUv.x * 30.0); float stripe = step(0.0, s); gl_FragColor = vec4(vec3(stripe), 1.0); }
4. 圆形 / Circle (distance)
varying vec2 vUv; void main() { float d = distance(vUv, vec2(0.5)); float c = 1.0 - smoothstep(0.3, 0.32, d); gl_FragColor = vec4(vec3(c), 1.0); }
